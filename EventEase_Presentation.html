Executive Summary & Motivation

The Problem

  • Physical ticket counters suffer long queues and manual errors.
  • Lack of a centralized portal to discover local concerts, tech summits, and workshops.
  • Difficulty in tracking booked tickets for attendees.

The Solution (EventEase)

  • Centralized online web application for instant event discovery.
  • Real-time seat availability & automatic price calculations in ₹.
  • User account portal storing all booked e-ticket passes securely.

Key Project Features

6 Core Pages

Home, Events Catalog, Services, About Us, Ticket Booking, and Contact Us.

Search & Filter

Filter events by categories (Tech, Music, Workshop, Sports, Art) and keywords.

Pass Tiers

Choose Standard or VIP Pass (+50% VIP lounge multiplier) with quantity selection.

Indian Rupee Pricing

All ticket rates and calculations displayed natively in Indian Rupees (₹).

User Management

Complete Sign Up, Login, and Profile Dashboard using ASP.NET Session state.

Digital Pass System

Auto-saves booked tickets directly to the user's account profile dashboard.

Booking & Pricing Calculation Workflow

Price Calculation Formula:
Total Amount (₹) = (Base Event Price × Tier Multiplier) × Quantity * Standard Pass = 1.0x Multiplier | VIP Pass = 1.5x Multiplier
Step 1: Input Validation

Validates Name, Email, Phone, and restricts Ticket Quantity between 1 and 10.

Step 2: Order Auto-Save

Generates unique Reference ID (e.g. EE-8A92B104) and saves ticket to BookingsRepository.
